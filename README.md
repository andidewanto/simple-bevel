# Simple Bevel

**English** · [Bahasa Indonesia](#bahasa-indonesia)

Round (fillet) or chamfer edges, edge chains with mitre joints, and 2D corners of flat faces. Free SketchUp extension by Andi Dewanto — Windows & macOS, SketchUp 2021+. Version **1.5.1**, which adds inside corners on end faces with holes, such as window frames.

- Website: https://andidewanto.github.io/simple-bevel/
- Download: [`downloads/ad_simple_bevel-1.5.1.rbz`](downloads/ad_simple_bevel-1.5.1.rbz)
- Tutorial (English / Indonesian): https://andidewanto.github.io/simple-bevel/tutorial.html
- Install: SketchUp › **Extensions › Extension Manager › Install Extension…** › choose the `.rbz`.
- More extensions: https://andidewanto.github.io/sketchup-extensions/

Contact & bug reports: andidewanto@gmail.com
